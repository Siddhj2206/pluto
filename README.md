# pluto

Pluto turns machines you own into a place to run CI, builds, dev servers and scheduled tasks, and using them from any device feels local.

**This is a rewrite, and nothing is usable yet.** The first goal is running a real GitHub Actions job on your own machine, in a fresh container, by changing only `runs-on`.
