# pluto

Pluto turns machines you own into a place to run CI, builds, dev servers and scheduled tasks, and using them from any device feels local.

**This is a rewrite.** GitHub Actions CI, tasks and schedules work on a single Linux machine. See [what's built and what's next](docs/product.md).
